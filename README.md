## Introduction
Nonnegative Tucker decomposition (NTD) and its sparse variants are effective tools for extracting latent features from multiway data. Existing sparse NTD methods evaluate and prune individual entries through element-wise sparsity penalties such as the $\ell_1$-norm. However, such individual evaluation and pruning overlook the joint contributions of each feature across different latent components, impairing the quality of extracted features and interpretability of the model. In this paper, we propose a novel group-sparse and graph-regularized nonnegative Tucker decomposition with $\ell_{2,1}$-norm (GGSNTD) method. Rather than evaluating features individually using element-wise penalties, our method employs the $\ell_{2,1}$-norm to impose group sparsity on factor matrices. This group sparsity evaluates each feature group as a whole and retains or discards it accordingly, accounting for the joint contribution of each feature across different latent components, thereby extracting more informative features and improving model interpretability. Additionally, the GGSNTD method employs graph regularization to preserve the intrinsic manifold structure of data. Although the nonconvexity of NTD and the nonsmoothness of the $\ell_{2,1}$-norm make GGSNTD difficult to optimize, we develop an Alternating Proximal Group Shrinkage (APGS) algorithm to provide an efficient and convergent scheme for solving GGSNTD. Moreover, we prove that the bounded sequence generated by our algorithm globally converges to a critical point and analyze the per-iteration complexity of our algorithm. Experimental results on six real-world benchmark datasets demonstrate that GGSNTD outperforms several state-of-the-art clustering methods.

This package contains code for the GGSNTD problem in the paper[<sup>1</sup>](#refer-id). 

## Matlab code
A toy example explains how to use this function. For "GGSNTD", before running it, first add the toolbox 'tensortoolbox'[<sup>2</sup>](#refer-id) (www.tensortoolbox.org) to the running path of matlab, and then run the function '[main_Run_me.m](GGSNTD/main_Run_me.m)'. 


## Data
This code has built-in the FashionMNIST and Pixraw10P datasets mentioned in our paper[<sup>1</sup>](#refer-id), and the rest of the data can be downloaded from the mentioned public website.
